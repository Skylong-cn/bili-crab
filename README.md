# Bili Crab

> 跨平台 B 站在线视频下载器 — Electron + React + aria2c + ffmpeg
>
> **当前版本**：V2.05（2.0.5）　·　**开发者**：Skylong　·　**平台**：Windows 10/11（x64）、macOS 12+（Apple Silicon）　·　**版权**：© 2026 Skylong

Bili Crab 是一款专注于 **B 站在线视频下载** 的桌面工具。它把你**有权观看**的视频保存为本地 MP4 或 MP3，支持扫码登录、清晰度选择、单视频/合集两种下载模式、批量下载（BV / av / ep / ss / 链接）、封面字幕弹幕、主题切换、下载历史和自动更新。

软件只调用 B 站公开接口，**不提供会员破解、DRM 绕过、自动登录或风控绕过**，也不收集、不上传任何用户数据。下载内容仅供个人学习、研究与离线观看。

> **发布说明**：本仓库只发布**二进制安装包、使用说明书和演示视频**，**不公开源代码**。自动更新与 Release 更新源为 `Skylong-cn/bili-crab`。

## 软件概述

### 它是什么

Bili Crab 是一个**在线视频下载器**，不是录屏工具、不是客户端缓存转换器，也不是万能媒体工具。它的目标是把「粘贴链接 → 解析 → 选择 → 下载」这条链路做稳：

- 输入 BV / av / ep / ss / 完整链接 / b23 短链；
- 解析标题、UP 主、分 P、番剧信息与实际可用清晰度；
- 选择 MP4（音视频无损合并）或 MP3（音频转码）；
- 可选保存封面、CC 字幕、弹幕；
- 任务进入队列，由 aria2c 多线程下载、ffmpeg 合并。

### 两种下载模式

V2.03 起，下载入口明确拆分为两个模式：

| 模式 | 适合 | 行为 |
|---|---|---|
| **单视频下载** | 单个普通视频、当前打开的番剧单集 | 只下载当前视频/单集；**不会自动打开合集** |
| **合集下载** | 视频所属合集、UP 主空间合集/列表 | 解析合集/列表，弹窗选择剧集；支持全选/单选、统一清晰度 |

单视频模式粘贴空间合集链接会提示切换到合集模式；合集模式粘贴非合集视频会提示切换到单视频模式。模式不会静默替你切换。

### 不做什么

- ❌ 不破解大会员、付费内容、DRM、地区限制或试看限制；
- ❌ 不绕过风控、不自动登录、不提供验证码绕过；
- ❌ 不收集数据、不上传下载记录或 Cookie；
- ❌ 不支持旧版 v1.4 的「客户端缓存转码 / 导出」（`video.m4s` / `audio.m4s` / `.vclip`）。

## 功能特性

### 下载

- ✅ **多格式输入**：BV / av / ep / ss / 完整链接 / b23.tv 短链
- ✅ **单视频模式**：只下当前视频或番剧单集，不自动展开合集
- ✅ **合集模式**：视频页合集自动识别、空间合集链接、全选/单选剧集
- ✅ **批量下载**：每行一个 BV / av / ep / ss / 链接，逐条解析、逐条选清晰度
- ✅ **番剧单集**：`ep123456` 精确到该集；`ss12345` 默认取该季第 1 集
- ✅ **多线程**：aria2c JSON-RPC，支持暂停 / 继续 / 取消、并发队列与去重
- ✅ **自动合并**：ffmpeg 合并 DASH 音视频（不重编码）
- ✅ **MP3 输出**：ffmpeg / libmp3lame 取最佳可用音轨转码 320 kbps
- ✅ **附加内容**：封面图片、CC 字幕（SRT）、弹幕（XML）

### 体验

- ✅ **扫码登录**：手机 B站 App 扫码，登录态保存在本机
- ✅ **清晰度覆盖 360P → 8K**：按正确排序展示，灰/锁状态明确
- ✅ **三态主题**：浅色（默认像素风）/ 深色 / 跟随系统
- ✅ **自定义控件与像素动效**：卡片倾斜、按钮按压、像素粒子、主题翻转
- ✅ **下载历史**：最多 500 条，可播放、打开目录、删除记录
- ✅ **设置**：下载目录、并发、连接数、分片数、User-Agent、外观
- ✅ **自动更新**：启动静默检查、后台下载、SHA256 校验、两选项提示

### 安全与发布

- ✅ **发布加固**：asar 打包、renderer + 主进程混淆、fuses、生产环境禁用调试入口
- ✅ **自动更新校验**：读取同一 Release 的 `SHA256SUMS.txt`
- ✅ **只发布二进制/说明书/视频**：不公开源代码
- ❌ 不提供账号共享、会员凭据或任何绕过能力

## 完整使用说明

### 1. 扫码登录

- 在登录卡片点「扫码登录」，用手机 **哔哩哔哩 App** 扫一扫并确认。
- 未登录最高 **480P**；登录普通账号最高 **1080P**；大会员账号可解锁 1080P+ / 1080P60 / 4K / HDR / 杜比视界 / 8K（需视频本身提供且有观看权限）。
- 登录态保存在本机 `settings.json`，不会上传；更换电脑需要重新扫码。
- 点「退出登录」清除本机 Cookie；不影响手机端登录。

### 2. 单视频模式

适用于单个普通视频或当前打开的番剧单集：

1. 确认顶部为 **单视频下载**；
2. 粘贴 BV / av / ep / 完整视频链接 / b23 短链；
3. 解析后选择清晰度、格式、附加内容；
4. 开始下载。

**重要**：单视频模式只下载当前视频/单集，**不会自动打开合集**。如果该视频属于某个合集，也不会自动展开。

### 3. 合集模式

适用于视频所属合集或 UP 主空间合集/列表：

1. 切换顶部为 **合集下载**；
2. 粘贴视频链接或空间合集链接；
3. 解析后弹窗列出剧集，默认全选，可取消/勾选单集；
4. 统一选择清晰度与 MP4/MP3，开始下载；
5. 文件输出到 `下载目录/合集标题/` 子文件夹。

空间合集链接格式：

```text
https://space.bilibili.com/<mid>/lists/<seasonId>?type=season
```

- `mid`：UP 主数字 ID；
- `seasonId`：合集 / 列表 ID；
- 链接需公开可访问。

**跨模式提示**：

- 单视频模式粘贴空间合集链接 → 提示切换到合集模式；
- 合集模式粘贴非合集视频 → 提示切换到单视频模式。

合集内某集缺少所选清晰度时，自动降级到该集可用的下一档并标注；单集失败单独提示，不影响其他集。

### 4. 批量下载（BV / av / ep / ss / 链接）

批量输入支持：

| 类型 | 示例 | 说明 |
|---|---|---|
| BV 号 | `BV1xx411c7mD` | 普通视频 |
| av 号 | `av170001` | 自动转 BV |
| ep 号 | `ep123456` | **番剧/剧集单集**，精确到该集 |
| ss 号 | `ss12345` | **番剧/剧集季度**，默认解析该季第 1 集 |
| 完整链接 | 普通视频 / `bangumi/play/ep...` / `ss...` 链接 | 自动识别 |
| b23 短链 | `https://b23.tv/xxxxxx` | 批量中自动展开 |

使用步骤：

1. 每行一个编号/链接，或用空格、逗号、分号分隔；
2. 点「解析视频」，逐条显示标题、UP 主与可用清晰度；失败项单独提示；
3. **每个条目单独选择清晰度**；统一选择 MP4 / MP3 与附加内容；
4. 点「批量加入」，任务按顺序进入队列并去重。

关于 ep / ss：

- `ep` 精确到单集，适合只下载某一集；
- `ss` 只解析该季**第 1 集**，**不会自动展开整季**，避免一次加入过多任务；
- 要下其他集：在番剧页面选择该集，复制对应 `ep` 链接，或把目标 ep 号逐条加入批量列表；
- 多 P 普通视频在批量中默认第 1 P，其他分 P 请单独解析。

队列行为：默认最多同时下载 3 个任务，可在设置中调整；单条失败不影响其他任务。

### 5. 清晰度选择

正确顺序（从低到高）：

| 清晰度 | 标签 | 账号 |
|---|---|---|
| 360P | 流畅 | 无需登录 |
| 480P | 清晰 | 无需登录（匿名上限） |
| 720P | 高清 | 免费账号 |
| 720P60 | 高帧率 | 免费账号 |
| 1080P | 超清 | 免费账号（登录后最高档） |
| 1080P+ | 高码率 | 大会员 |
| 1080P60 | 高帧率 | 大会员 |
| 4K | 超清 | 大会员 + 观看权限 |
| HDR | 真彩 | 大会员 + 观看权限 |
| 杜比视界 | 杜比 | 大会员 + 观看权限 |
| 8K | 超高清 | 大会员 + 观看权限 |

> 1080P 系列全部在 4K 之前，8K 最后。灰色 = 视频没有该档；带锁 = 账号权限不足。清晰度以 B站实际下发为准。

### 6. MP4 / MP3 与 Hi-Res

| 格式 | 内容 | 处理 |
|---|---|---|
| **MP4** | 视频 + 音频 | DASH 流用 ffmpeg `-c copy` 无损合并 |
| **MP3** | 仅音频 | ffmpeg / libmp3lame 取最佳可用音轨转码 320 kbps |

- 一次任务只输出一种格式；需要两种请分别下载。
- MP3 是纯音频文件；封面等附加内容另存为独立图片。
- **Hi-Res**：B站音质档次之一，是否可用取决于视频源与账号权限。MP3 会取最佳可用音轨，但**不承诺** Hi-Res 无损封装或杜比音效直出。

### 7. 下载目录与文件命名

- 默认下载目录：
  - Windows 绿色版：`<exe 同目录>\下载`
  - Windows 安装版 / macOS：系统「下载」目录下的 `BiliCrab`
- 可在设置中更换；建议选空间充足的本地磁盘。
- 单集文件名：`BV号_P分P_清晰度.mp4`（或 `.mp3`），例如 `BV1xx411c7mD_P1_1080P.mp4`。
- 合集任务输出到 `下载目录/合集标题/` 子文件夹。
- 附加文件：`.cover.jpg`、`.语言.srt`、`.danmaku.xml`。

### 8. 下载历史

- 「历史」页记录标题、分 P、清晰度、大小、完成时间、保存路径。
- 最多保留 500 条。
- 操作：播放、打开所在目录、删除记录、清空历史。
- **删除记录/清空历史不会删除已下载文件**；请到下载目录手动删除。

### 9. 外观与主题

- 默认 **浅色像素风**；支持 **深色** 与 **跟随系统**。
- 切换方式：标题栏右上角主题按钮循环切换；或「设置 → 外观」三态选择。
- 切换立即生效、无需重启；偏好写入 `settings.json`，下次启动沿用。
- 跟随系统会随 macOS / Windows 外观自动切换。

### 10. 设置

| 设置项 | 默认 | 说明 |
|---|---|---|
| 下载目录 | 见上 | 成品与附加文件保存位置 |
| 外观主题 | 浅色 | 浅色 / 深色 / 跟随系统 |
| 最大并发下载数 | 3（1–10） | 同时下载几个任务；建议 3–5 |
| 每服务器连接数 | 16（1–32） | 单文件 HTTP 连接数 |
| 分片数 | 16（1–32） | 单文件切块数；连接数 ≤ 分片数才有意义 |
| User-Agent | 自动 | 一般无需修改 |
| B站 Cookie | 扫码后自动写入 | 高级选项，不建议手动填 |

> 不要盲目拉满并发/连接/分片；B站对单 IP 有带宽与频率限制。

### 11. 自动更新

- **更新源**：GitHub Releases `Skylong-cn/bili-crab`。
- **启动静默检查**：后台读取最新 Release；发现新版本后后台下载。
- **镜像回退**：国内直连 GitHub 超时自动尝试 `https://gh-proxy.com/`，无需配置；仍失败则静默跳过。
- **SHA256 校验**：读取同一 Release 的 `SHA256SUMS.txt`，校验失败不安装、只写日志。
- **两选项提示**：下载完成只提供「立即更新」/「下次启动软件时更新」；没有「忽略此版本」。
- **下次启动**：选择后者后，下次启动会**自动安装并重启**，无需再次确认。
- **数据保留**：立即更新重启并保留设置 / 历史 / 登录 / 已下载文件。
- **发布范围**：只发布二进制、说明书与演示视频，不公开源代码。

### 12. 数据位置与便携性

| 版本 | 设置 / 历史 / 登录态 | 默认下载目录 |
|---|---|---|
| Windows 绿色版 | `<exe 同目录>\Bili Crab Data\` | `<exe 同目录>\下载` |
| Windows 安装版 | `%APPDATA%\Bili Crab\` | 系统「下载」下的 `BiliCrab` |
| macOS | `~/Library/Application Support/Bili Crab/` | 系统「下载」下的 `BiliCrab` |

- 绿色版是真便携：把 exe 与 `Bili Crab Data` 一起拷走，登录态、设置与历史保留。

- 登录 Cookie 属敏感信息，不要分享 `settings.json`。
- 旧版 v1.4 的 `data/`、`tools/BBDown.data` 不会被 V2.05 读取。

## 常见问题

<details>
<summary><b>解析失败或提示需要登录？</b></summary>
<p>确认是普通视频/番剧稿件；高画质或受限内容先扫码登录再重新解析。查看日志错误码：<code>-101</code> 多为未登录/失效，<code>-403</code> 多为权限不足。</p>
</details>

<details>
<summary><b>为什么单视频模式没有出现合集？</b></summary>
<p>V2.03 起单视频与合集拆分为两个模式。单视频模式只下当前视频/单集，不会自动打开合集；需要合集中下载请切换到「合集下载」。</p>
</details>

<details>
<summary><b>批量下载支持番剧吗？ep 和 ss 有什么区别？</b></summary>
<p>支持。<code>ep</code> 精确到单集；<code>ss</code> 解析该季并默认只取第 1 集，不会自动展开整季。要下其他集，请在番剧页面选择该集后复制对应 ep 链接，或把 ep 号逐条加入批量列表。</p>
</details>

<details>
<summary><b>为什么 1080P 排在 4K 前面？</b></summary>
<p>B站按分辨率 + 帧率 + 码率综合排序。1080P / 1080P+ / 1080P60 都属于 1080P 系列，高于 720P 但低于 4K；8K 最后。V2.00 已修正旧版 116/120 标签映射。</p>
</details>

<details>
<summary><b>清晰度灰色 / 带锁？</b></summary>
<p>灰色表示视频没有该档；带锁表示需要登录或大会员权限。已登录大会员仍带锁，说明该视频超出账号观看权限。</p>
</details>

<details>
<summary><b>MP3 和 MP4 怎么选？</b></summary>
<p>需要画面选 MP4（无损合并）；只需要声音选 MP3（320 kbps 转码）。两者单选，需要两种请分两次下载。</p>
</details>

<details>
<summary><b>Hi-Res / 杜比音效为什么没有？</b></summary>
<p>是否可用取决于视频源与账号；MP3 取最佳可用音轨转码，不承诺 Hi-Res 无损封装或杜比 passthrough。</p>
</details>

<details>
<summary><b>下载速度慢 / aria2c 启动失败？</b></summary>
<p>把软件目录加入杀毒软件白名单，确认 <code>resources/aria2c/...</code> 未被隔离。速度慢时先把分片加到 32，再把并发加到 5，不要全部拉满。</p>
</details>

<details>
<summary><b>杀毒软件报毒 / Windows 未知发布者？</b></summary>
<p>安装包未做商业代码签名，且下载器会调用下载与媒体处理能力，可能出现启发式误报。请只从信任来源获取；软件无广告、无捆绑、无后台常驻。</p>
</details>

<details>
<summary><b>macOS 提示无法验证开发者 / 已损坏？</b></summary>
<p>未公证应用的 Gatekeeper 拦截。右键「打开」，或到「系统设置 → 隐私与安全性」点「仍要打开」。当前仅 arm64 版本。</p>
</details>

<details>
<summary><b>更新会丢数据吗？为什么没有「忽略」？</b></summary>
<p>更新只替换程序文件，设置、历史、登录与已下载文件保留。更新是强制的，只能选「立即更新」或「下次启动软件时更新」；选后者，下次启动自动安装并重启。</p>
</details>

<details>
<summary><b>离线或更新失败会怎样？</b></summary>
<p>静默跳过，不弹窗、不影响使用；下次联网启动重试。直连 GitHub 超时会自动尝试 <code>gh-proxy.com</code> 镜像。</p>
</details>

<details>
<summary><b>换电脑后登录和历史还在吗？</b></summary>
<p>绿色版把 exe 与 <code>Bili Crab Data</code> 一起拷走即可保留；安装版/macOS 数据在系统用户目录，换电脑需重新扫码与设置。</p>
</details>

<details>
<summary><b>如何彻底卸载？</b></summary>
<p>安装版：卸载后删除 <code>%APPDATA%\Bili Crab</code>；绿色版：删除 exe 与 <code>Bili Crab Data</code>；macOS：删除应用与 <code>~/Library/Application Support/Bili Crab</code>。</p>
</details>

<details>
<summary><b>能下载番剧、付费课程、直播吗？</b></summary>
<p>支持可访问的番剧稿件（以账号权限为准）；付费 DRM、课程、直播等不在承诺范围，不绕过付费、会员或风险控制。</p>
</details>
